Pro tip

Apni classes add karo

chai.extend() se tum runtime mein apni khud ki custom utility classes add kar sakte ho. Koi build step nahi, bas ek JS object.

Aur agar koi unknown chai- class use karoge toh console mein warning milegi.

chai.extend({
  "chai-my-btn": "background: purple; color: white; padding: 8px 16px",
  "chai-neon": "color: #39ff14; font-weight: bold",
});

chai.scan(); // re-apply
